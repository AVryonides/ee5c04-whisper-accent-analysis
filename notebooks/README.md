## Original modified Colab notebooks

These are publication copies of the two original modified notebooks identified by the author. Code and explanatory cells are retained, except private Google Drive output directories are replaced with generic `/content/assignment_results` and `/content/audio_export` paths. Saved outputs, execution counts, cell metadata and widget state are cleared to avoid publishing tokens, transcripts, or account state. Original local files are unchanged.

The saved configuration is Korean English. Change dataset IDs, model IDs, accent labels, output directories and CSV filenames consistently for each experiment. For the baseline use `openai/whisper-tiny`; the decoding copy currently uses the Korean fine-tuned model. Download exported CSVs from the Colab runtime before it resets. The extra verification cell expects all baseline CSVs already in the results directory.

The fine-tuning notebook adapts the assignment notebook and Sanchit Gandhi’s [Hugging Face tutorial](https://huggingface.co/blog/fine-tune-whisper); existing attribution is preserved. No blanket licence is applied to third-party teaching material.
