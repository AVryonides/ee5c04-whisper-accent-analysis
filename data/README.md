## Prediction CSVs held locally

The ten original prediction CSVs were found and inventoried in `manifest.json`. They contain reference transcripts and hypotheses. None of the five upstream dataset cards declared a redistribution licence when checked on 30 October 2026, so these files and audio are excluded from this public repository. Public availability does not establish redistribution permission. Obtain clarification from the dataset owner before publishing.

For authorised local analysis, put the original files with the exact manifest filenames in this directory. They remain ignored by Git. The manifest records SHA-256 checksums, row counts, and column names without transcript contents.
